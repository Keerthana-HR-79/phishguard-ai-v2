Install in 5 steps

1
Download & unzip the extension
Click the download button above, then unzip the file somewhere you'll remember.
2
Open Chrome's extensions page
Type chrome://extensions into the address bar and press Enter.
3
Enable Developer mode
Toggle Developer mode on in the top-right corner.
4
Load unpacked
Click Load unpacked and select the unzipped phishguard-extension folder.
5
Start the backend
Make sure the FastAPI backend is running on port 8000 so the extension can check URLs.
Note: the extension talks to your local PhishGuard backend at http://localhost:8000. Start it with uvicorn main:app --port 8000 in the backend/ folder before browsing.
