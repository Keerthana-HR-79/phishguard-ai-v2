PhishGuard Chrome Extension

Check every page you visit automatically. The extension sends each tab's URL to the PhishGuard backend and warns you the moment a tab looks like phishing.

⬇ Download Extension
⚡Instant checks on every tab
🔔Live warning banner on risky pages

🎨Clean one-click verdict popup

Install in 5 steps

1
Download & unzip the extension
Click the download button above, then unzip the file somewhere you'll remember.
2
Open Chrome's extensions page
Type chrome://extensions into the address bar and press Enter.
3
Enable Developer mode
Toggle Developer mode on in the top-right corner.
4
Load unpacked
Click Load unpacked and select the unzipped phishguard-extension folder.
5
Pin it and start scanning
It's preconfigured to use the hosted backend — click the icon on any page. The first check after a while may take ~30–60s while the free backend wakes up.
Note: the extension is preconfigured to call the hosted PhishGuard backend, so there's nothing to run locally. To point it at a different backend, set apiBase in the extension's storage (see extension/config.js).
